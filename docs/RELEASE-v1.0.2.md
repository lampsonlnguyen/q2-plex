# Plex Music v1.0.2 — Home shortcut icon

- Adds a white, transparent 96 × 96 `pane.png` for Q2 Pod 1.9.6 Home shortcut previews.
- Retains the existing circular 52px and 40px list icons.
- Includes the new icon in the install ZIP and validates dimensions, transparency and antialiasing.
- Older firmware ignores the new icon. No playback or authentication changes.

Install the release ZIP at the microSD root, preserving existing .plex/auth.json, .plex/last-queue.json, .plex/fav.log and PlexMusic/. Restart the Q2. Select Plex Music as the Home shortcut to see the new icon on compatible firmware.

Physical-device validation remains pending. Unofficial Plex client; existing list artwork attribution: selfh.st/icons (CC BY 4.0).
